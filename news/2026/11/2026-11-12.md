## 2. 主要ニュース

### Apache HTTP Server：mod_http2の重大なコード実行脆弱性を修正

ApacheはCVE-2026-119618を公表した。HTTP/2のヘッダー処理に同期不備があり、ヒープ破損からリモートコード実行につながる。影響範囲はHTTP Server 2.4.55〜2.4.70、独立したmod_h2では2.0.8〜2.0.42で、HTTP Server 2.4.71に修正が含まれる。

**なぜ重要か：** 広く使われるWebサーバーの通信処理に関わるため、HTTP/2を有効にした環境では導入版と更新可否の確認を優先したい。確認した告知には実悪用の記載はなく、「悪用中」とは扱わない。

公開・発表日時：2026年11月11日12:19:30 UTC（21:19:30 JST）。  
出典：[開発者の公式告知](https://www.openwall.com/lists/oss-security/2026/11/11/13)、[Apache修正情報](https://httpd.apache.org/security/vulnerabilities_24.html)

### Node.js：HTTPSのメモリ漏えい、HTTP/2のDoSなどに更新

Node.js 26.13.1、24.22.3、22.23.5が公開された。CVE-2026-123864では、特定の応答処理を行うHTTPSサーバーから、未認証の相手に他接続のメモリが漏れる可能性があり、秘密鍵や別利用者の要求も含まれ得る。HTTP/2のプロセス停止・メモリ漏えい、TLSのクライアント証明書認証回避なども修正した。

**なぜ重要か：** アプリの条件次第で機密性と可用性の両方に影響するため、対応する系統の修正版へ更新し、実行環境やコンテナに古いランタイムが残っていないか確認したい。

公開日時：26.13.1は2026年11月11日16:44:25 UTC（11月12日01:44:25 JST）。24系・22系も同日16:44 UTC台に公開。  
出典：[公式セキュリティ告知](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases)、[26.13.1リリース](https://github.com/nodejs/node/releases/tag/v26.13.1)

### AWS Emulator：ローカルでAWS向けアプリを試す公開版

AWSは、CLIやSDKの接続先を切り替えてAWS APIをローカルで試せるAWS Emulatorを紹介した。対象期間には公開版v1.0.322が提供されており、Rustで実装された環境を開発・テストに利用できる。一方、READMEはAWSとの挙動差を明示し、本番運用やセキュリティ試験用ではないとしている。

**なぜ重要か：** クラウド資源の作成を伴う反復テストを手元で実施しやすくなるが、実環境での最終検証を置き換えられる範囲は慎重に見極める必要がある。

公開日時：v1.0.322は2026年11月11日00:32:13 UTC（09:32:13 JST）。これはソフトウェアの公開時刻であり、紹介ブログの初出時刻とは区別する。  
出典：[AWS公式解説](https://aws.amazon.com/blogs/aws/test-your-applications-against-aws-locally-with-aws-emulator/)、[公開版と変更内容](https://github.com/aws/aws-emulator/releases/tag/v1.0.322)

### IBM：Nighthawk r3と2027年の1,040量子ビット構成を計画

IBMはNighthawk r3を、520個のプログラム可能な量子ビットで1万回の量子演算を扱う設計として発表した。2027年には2基を接続した1,040量子ビットのシステムを目指し、量子計算と古典計算を組み合わせるプラットフォームの拡充も示した。これらは今後の設計・計画であり、既に利用可能なr2の実績とは異なる。

**なぜ重要か：** 量子ビット数だけでなく、接続・演算品質・古典計算との連携を一体で評価する材料になる。ただし計画の公表を商用上の優位性が実証されたこととは同一視しない。

発表日時：2026年11月11日07:00 EST（UTC−5、21:00 JST）。  
出典：[IBM発表全文](https://www.prnewswire.com/news-releases/ibm-quantum-nighthawk-demonstrates-new-levels-of-speed-and-quality-with-plans-to-scale-beyond-1-000-qubits-in-2027--302935826.html)
