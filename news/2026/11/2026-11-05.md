## 2. 主要ニュース

### APTの検証回避、パッケージ差し替えからroot権限のコード実行も

DebianやUbuntuなどが使うAPTに、ダウンロード検証を回避されるCVE-2026-109518が見つかった。HTTP通信やミラーを操作できる攻撃者がリダイレクトと再試行を悪用し、インストールされるパッケージを差し替え得る。再試行設定が有効な場合に影響し、Debian 12とUbuntu 22.04以降では標準で有効だ。Debian 13向け3.0.4など、各系列に修正版がある。

**なぜ重要か（考察）：** ソフトウェア供給の入口を狙うため、利用中の配布版の更新状況を優先して確認したい。公式発表に実際の悪用の記載はない。

発表：11月4日13:00:16 UTC+1（21:00:16 JST）。  
出典：[APT開発者の告知](https://lists.debian.org/deity/2026/11/msg00005.html)、[Ubuntuの対象・修正版](https://ubuntu.com/security/CVE-2026-109518)

### Chrome、eMudhraのG1ルートにも新たな信頼制限

Chrome Root Programは、emSign Root CA - G1につながるTLS証明書に新たな制限を発表した。最も早い証明書透明性のタイムスタンプ（SCT）が11月16日23:59:59 UTCより後の証明書は、Chrome 153以降で原則として信頼されなくなる。それ以前のSCTを持つ証明書は今回の変更の対象外だ。

**なぜ重要か（考察）：** 前号で扱ったG3系の事故対応とは別の進展で、サイト運営者はG1経由の証明書発行・更新経路も点検したい。

発表：11月4日09:15:42 UTC-8（11月5日02:15:42 JST）。  
出典：[Chrome Root Programの告知](https://www.mail-archive.com/public@ccadb.org/msg00592.html)、[Googleの説明](https://blog.google/security/protecting-chrome-and-android-users-from-compromised-emudhra-intermediate-ca-certificates/)

### Apache OFBiz、認証前RCEなどの脆弱性を一括告知

Apache OFBizの担当者は、24.09.08未満に影響する複数の脆弱性を公表し、既に公開された24.09.08への更新を推奨した。認証前のコード実行、認可回避、固定されたJWT鍵を使った管理者アクセスなどが含まれる。

**なぜ重要か（考察）：** 業務システムの公開範囲と更新を確認したい。告知は実際の悪用を確認したとは述べていない。

発表：11月4日17:12:59 UTC+1（11月5日01:12:59 JST）。  
出典：[Apache担当者の告知](https://www.openwall.com/lists/oss-security/2026/11/04/9)

### Rails、重大なファイル読み書きなど21件を修正

Rails 8.0.5.2と8.1.4.1が21件のセキュリティ問題を修正した。Active Storageの画像解析では、信頼できないファイルのアップロードを許し、ImageMagickの設定など一定の条件が重なると、任意ファイルの書き込みや読み取りにつながる問題がある。修正にはmini_magick 5.1以降も必要だ。

**なぜ重要か（考察）：** 画像処理を使うアプリでは設定と依存関係を含めて点検したい。すべてのRailsアプリが無条件で遠隔実行されるという意味ではない。

発表：11月3日21:58:37 UTC-5（11月4日11:58:37 JST）。  
出典：[Rails担当者の告知](https://www.openwall.com/lists/oss-security/2026/11/04/2)、[詳細](https://github.com/rails/rails/security/advisories/GHSA-f3w6-w445-fwh9)

### Symfony、HTTP通信時の認証情報流出などを修正

PHPフレームワークSymfonyの7.4.23などが複数のセキュリティ修正を含めて公開された。ScopingHttpClientでは、攻撃者がURLの先頭を制御できる条件で、既定の認証情報が別の接続先に送られ得る問題がある。HTTP Clientの修正版は5.4.56、6.4.50、7.4.23、8.1.11だ。

**なぜ重要か（考察）：** 外部URLを扱うアプリでは、サービス間通信の資格情報が漏れる経路を塞ぐ必要がある。

公開：7.4.23は11月4日11:29:14 UTC（20:29:14 JST）。  
出典：[公式Release](https://github.com/symfony/symfony/releases/tag/v7.4.23)、[公式アドバイザリ](https://github.com/symfony/symfony/security/advisories/GHSA-gq53-v8w2-gjhj)

### OpenAI、開発ツール企業Pierreの買収を発表

OpenAIは、Gitを使ったコード保存やレビューのツールを手がけるPierre Computerの買収を発表した。Code Storageの機能をCodexに取り込む方針で、同社のオープンソース製品は継続する。取引の完了には規制当局の承認などが必要だ。

**なぜ重要か（考察）：** AIによるコード生成だけでなく、変更の保存・レビューまで開発基盤の競争が広がる。

公式SNSでの発表：11月4日15:15:43 UTC（11月5日00:15:43 JST）。  
出典：[OpenAI公式発表](https://openai.com/index/openai-to-acquire-pierre/)、[公式投稿](https://x.com/OpenAINewsroom/status/2117999237745049883)

### Claude Code、権限確認や失敗表示を修正

Claude Code 2.1.318は、権限確認の表示前に入力したキーが回答として扱われる問題を修正した。設定の保存失敗やAPIエラーが成功のように表示される問題なども修正している。

**なぜ重要か（考察）：** エージェントに操作を任せる際は、利用者の承認と実際の処理結果を正しく伝えることが重要だ。

公開：11月4日00:01:03 UTC（09:01:03 JST）。  
出典：[公式Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

### ST、産業・自動車向けマイコン基盤を統合

STMicroelectronicsは産業、自動車、ロボット向けに共通のSTM32マイコン基盤を発表した。STM32Aの一部をサンプル提供し、広範な提供は2027年を予定している。

**なぜ重要か（考察）：** 異なる用途間でコードや開発ツールを再利用しやすくなれば、組み込み製品の開発負担を減らせる。

発表：11月4日01:00 ET（06:00 UTC／15:00 JST）。  
出典：[ST公式配信](https://rss.globenewswire.com/news-release/2026/11/04/3395000/0/en/stm32-summit-2026-stmicroelectronics-announces-its-unified-mcu-platform-addressing-technology-convergence-across-industrial-automotive-and-physical-ai-applications.html)
