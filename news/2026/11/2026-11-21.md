## 2. 主要ニュース

### CISA、悪用確認済みの脆弱性にApache Roller・vCenterなど4件を追加

CISAのKEVカタログにApache Roller（CVE-2026-129448）、VMware vCenter（CVE-2026-123890）、SAP NetWeaver（CVE-2025-42884）、Cisco Expressway（CVE-2026-76466）が加わった。Rollerは従来のCVE-2026-82384と同じ根本原因だが、対象バージョンがより広い。BroadcomはvCenterの認証回避をCVSS 9.8とし、修正版への更新を案内している。

**なぜ重要か：** 理論上の危険度だけでなく悪用実績に基づく追加であり、外部公開資産を優先して、修正版の適用と侵害痕跡の確認を並行したい。11月23日は米連邦機関向けの期限で、一般企業の一律期限ではない。  
**公開日時：** 11/21 02:48:39 JST（11/20 17:48:39 UTC、KEVカタログ公開時刻）。  
**出典：** [CISA公式カタログデータ](https://raw.githubusercontent.com/cisagov/kev-data/develop/known_exploited_vulnerabilities.json)／[Broadcom公式アドバイザリ](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39495)／[Cisco公式アドバイザリ](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-vcs-static-cred-hr7EWZ8t)

### NGINX続報：UbuntuとAWSがそれぞれ修正パッケージを案内

CanonicalがUSN-9182-1を公表し、NGINXのサービス停止などにつながる3件（CVE-2026-123640、CVE-2026-125283、CVE-2026-118899）について、Ubuntuのリリース別に修正済みパッケージを案内した。これは先行するUSN-9159-1で告知されたHTTP/2の重大修正の再掲ではない。別途AWSはAmazon Linux 2／2023／2027で修正済みのnginxパッケージを配布し、Elastic Beanstalk向けの修正も公開した。Elastic Beanstalkで今回のHTTP/2問題の影響を受けるのは、独自のnginxリスナーでHTTP/2を有効にした環境だとAWSは説明している。

**なぜ重要か：** 先行告知を見て更新済みでも、追加告知のパッケージ版に達しているか確認したい。ディストリビューションのバックポートは上流のバージョン番号だけでは判別できない。  
**公開日時：** AWSは11/20 07:00 JST（11/19 15:00 PST、本号の対象期間の開始時刻）。Canonicalは11/20 12:23:12 JST（03:23:12 UTC、公式メーリングリスト）。  
**出典：** [追加告知](https://ubuntu.com/security/notices/USN-9182-1)／[公開メール](https://lists.ubuntu.com/archives/ubuntu-security-announce/2026-November/011698.html)／[先行告知](https://ubuntu.com/security/notices/USN-9159-1)／[AWS公式告知](https://aws.amazon.com/security/security-bulletins/2026-192-aws/)

### Etherpad、認証前にサーバー上のファイルを読まれる重大な問題

GitHub Advisory Databaseが、共同編集ツールEtherpadのCVE-2026-114516を登録した。対象は `ep_etherpad-lite` 1.8.14以降、3.3.3未満。公開環境では、ログインを必須にしていても、Etherpadの実行ユーザーが読めるファイルに影響が及び得る。

**なぜ重要か：** 外部に公開していた場合は3.3.3以降への更新に加え、アクセス記録を保全し、設定ファイル内の認証情報の露出を点検したい。  
**公開日時：** 11/20 09:23:45 JST（00:23:45 UTC、GitHub Advisory Database掲載。CVEレコードの初出は06:48:21 JSTで本号の範囲外）。  
**出典：** [GitHubアドバイザリ](https://github.com/advisories/GHSA-mc8w-wjhw-45x5)／[公開時刻の公式データ](https://raw.githubusercontent.com/github/advisory-database/main/advisories/github-reviewed/2026/11/GHSA-mc8w-wjhw-45x5/GHSA-mc8w-wjhw-45x5.json)

### Claude Code v2.1.329、フックの出所とセッション内のタスクを可視化

Anthropicは、フォルダーのフックがどこで宣言されているかを信頼確認画面に表示し、管理設定のフックの読み込み失敗を非対話型の実行環境でも通知するようにした。`/tasks` には、セッション内の予定タスクやフォークなどが表示される。

**なぜ重要か：** 共有リポジトリを開く際に自動実行設定の出所を確認しやすくなり、常駐する作業も見つけやすくなる。  
**公開日時：** 11/20 07:14:24 JST（11/19 22:14:24 UTC、公式リリースフィード）。  
**出典：** [公式リリース](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)／[公式フィード](https://raw.githubusercontent.com/anthropics/claude-code/main/feed.xml)
